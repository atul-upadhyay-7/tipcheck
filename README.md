# TipCheck

Sangyan Hackathon Track E prototype: an educational check for financial messages, with transparent red-flag cues. This is not a fraud detector, fact-checker, or investment advice.

## Get the starter code

Download `TipCheck-starter.zip` from the repository's files, extract it locally, then follow `README.md` inside the extracted project. The archive includes the React UI, FastAPI rules endpoint, optional TF-IDF training script, smoke tests, and setup notes. No account keys or paid APIs are needed.

## Prototype caveats

Rules and any locally trained model are illustrative only. A low or empty red-flag score does not mean a message is safe; links are not opened or verified, and no registration or financial claim is checked. Do not paste real names, phone numbers, account data, OTPs, or private messages. Use fictional examples for demos.
